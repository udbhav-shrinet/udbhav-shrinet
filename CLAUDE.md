# Repository conventions

## Commit and PR message footer

Do not use Claude Code's default attribution lines (no "🤖 Generated with Claude Code" line, no "Co-Authored-By: Claude" line, and no Claude session/chat links) in commit messages or pull request descriptions.

Instead, every commit message and PR description must end with a blank line followed by:

```
Edited by Udbhav
```

This applies to all commits and PRs in this repository, with no exceptions.
